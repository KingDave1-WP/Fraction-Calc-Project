Pedagogical Design & Architecture

How this tutorial teaches & its separated JSON data layer

1. Phone-First Working Paper & Custom Keypad

Typing fractions like 2/3 + 1/4 on a standard mobile keyboard requires toggling between letters, numbers, and symbols repeatedly. Our docked keypad puts digits, a dedicated fraction slash /, +, and = within thumb reach while rendering stacked fractions in real time.

2. Respectful Tone & Minimalist Tutor ("Axiom")

Teenagers aged 13–16 reject childish mascots and patronizing praise. Axiom uses a calm, peer-level editorial voice, lives in a compact top card on mobile (and a sticky sidebar on desktop), and keeps audio muted by default with full text parity via the Web Speech API.

3. Diagnostic Checking, Not Just Right/Wrong

Instead of simple string matching, the validation engine parses mathematical expressions into rational values and inspects numerator/denominator patterns. If a learner adds straight across (3/5 + 1/6 = 4/11), Axiom diagnoses why that happens. If they enter an unsimplified equivalent (8/12 instead of 2/3), Axiom confirms the value is right and nudges them to simplify.

4. Complete Content–Engine Separation

Every explanation, worked line, diagnostic rule, and progressive hint resides in LESSON_CONTENT. Swapping that single JSON object turns this engine into a tutorial for one-step equations or polynomials without changing UI code.
